# ServerOK - Серверное оборудование для бизнеса в Казахстане

Одностраничный сайт для продажи серверного оборудования.

## Особенности

- Адаптивный дизайн в светлых тонах
- Каталог из 9 серверов Dell, HP, Supermicro
- Форма заявки с отправкой на email
- Интеграция Яндекс.Карт
- SEO-оптимизация (sitemap.xml, robots.txt)
- Страница 404

## Структура проекта

```
serverok-03/
├── index.html          # Главная страница
├── styles.css          # Стили
├── script.js           # JavaScript функционал
├── 404.html            # Страница ошибки
├── robots.txt          # Файл для поисковых роботов
├── sitemap.xml         # Карта сайта
└── README.md           # Документация
```

## Запуск

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve
```

## Примечания

- Для полноценной работы Яндекс.Карт необходимо получить API ключ на https://developer.tech.yandex.ru/
- Замените `YOUR_API_KEY` в index.html на реальный ключ
- Добавьте реальные изображения серверов в папку проекта
